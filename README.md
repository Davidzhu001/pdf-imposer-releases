# PDF Imposer — Releases

This repository holds **installers only** for PDF Imposer, the print-shop
tool that imposes PDFs for book prepress (booklet, n-up, cards).

Download the latest version here:

**https://davidzhu001.github.io/pdf-imposer/**

- macOS: Apple Silicon (M1/M2/M3/M4) and Intel builds (`.dmg`)
- Windows: 64-bit installer (`.exe` / `.msi`, preview — job processing on
  Windows is not connected yet)

The source code lives in a private repository and is not published here.
